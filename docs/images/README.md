# README 用的截圖

`README.md` 與 `README.zh-Hant.md` 裡的圖片區塊目前是註解掉的，等這些檔案就位再把註解解掉
（同時刪掉那段文字示意圖）。兩份 README 引用**同一組**檔案，補一次就好。

| 檔名 | 拍什麼 | 注意 |
|---|---|---|
| `launcher.png` | 候選框浮在 Windows Terminal 之上，貼齊輸入游標，列出幾筆帶 `★` 的候選 | 這是唯一一定要有的一張。要看得出「候選框對齊的是游標，不是螢幕中央」 |
| `settings-commands.png` | 設定畫面的「命令字詞」頁，帶搜尋字串與來源標籤 | |
| `settings-general.png` | 設定畫面的「一般設定」頁 | 截圖前先確認畫面上沒有真實的機密過濾樣式或路徑 |
| `tray.png` | 系統匣右鍵選單（選用） | |

拍攝前：

- 用**乾淨的資料**。候選框與命令字詞頁會顯示從歷史學來的條目，那些是真實的工作內容——
  必要時先在設定畫面把歷史學來的條目篩掉，或換一個乾淨的使用者帳號拍。
- 提示字元不要出現內部主機名稱、專案代號或內部路徑。
- 深色與淺色隨你，但四張最好一致。
- 寬度約 1440px 以內即可，README 端會縮到 720px。
