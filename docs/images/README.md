## 現有兩張是怎麼拍的

刻意用**中文關鍵字**當查詢，這在技術上保證畫面乾淨：歷史學來的條目沒有關鍵字也沒有
說明，`Entry::haystack()` 只剩命令本文，中文查詢因此不可能命中它們。畫面上只會是內建目錄。

同一個查詢在繁中介面命中三筆、英文介面兩筆，因為 `usbipd detach --all` 是靠**說明**裡的
「掛載」命中的，而 `keywords_all` 的七語言聯集只覆蓋關鍵字、不覆蓋說明。這是真實行為。

終端機用 `-NoProfile` 另開，提示字元改成 `PS C:\>` 而非預設的 `PS C:\Users\<名字>>`，
避免使用者名稱入鏡。擷取範圍取 `DwmGetWindowAttribute` 的視覺邊界再內縮 2px——
`GetWindowRect` 含 DWM 陰影邊框，直接用會把背後視窗的邊緣帶進畫面。

## 補剩下幾張時

- **用乾淨的資料。**「命令字詞」頁預設會列出從歷史學來的條目，那些是真實的工作內容。
  截圖前先把來源篩選設成「內建」。
- 提示字元與路徑不要出現內部主機名稱、專案代號或內部路徑。
- 「一般設定」頁截圖前確認機密過濾樣式欄位裡沒有自訂的敏感字樣。
- 深色淺色隨意，但同一份 README 裡的幾張最好一致。
- 寬度約 800px 即可，README 端不再縮放。
